## Overview

A dark, futuristic single-page portfolio built with React and Vite. It highlights:

- Full-time PAT role and Cognizant internship
- AI / ML, Generative AI, and full-stack projects
- Live certificate gallery with lightbox
- Volunteering (NSS, Aksharadaan)
- Hackathons and achievements
- Resume view / download

Getting started
Prerequisites

Node.js 18+
npm

Install & run
Bashgit clone https://github.com/DattaSai13/portfolio.git
cd portfolio
npm install
npm run dev
Open the URL shown in the terminal (usually http://localhost:5173).
Build for production
Bashnpm run build
npm run preview
Output is in the dist/ folder.
